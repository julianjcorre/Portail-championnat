| Fichier | Contenu |
| --- | --- |
| [1-etat-actuel-v1.md](1-etat-actuel-v1.md) | Photo de l'application **telle qu'elle est aujourd'hui** (point de départ, à ne plus modifier). |
| [2-projet-v2-cloudflare.md](2-projet-v2-cloudflare.md) | Ce qui a été discuté et décidé pour la **2.0** : architecture, bascule, idées pour plus tard. |
| [3-plan-simple.md](3-plan-simple.md) | Le **plan de la V2 étape par étape**, expliqué simplement. |
| [HISTORIQUE.md](HISTORIQUE.md) | **Journal** de toutes les décisions et modifications, de la plus récente à la plus ancienne. |

Règle : chaque décision ou modification liée à la 2.0 ajoute une ligne datée dans `HISTORIQUE.md`. Si elle change le projet, mettre aussi à jour `2-projet-v2-cloudflare.md`. Le fichier `1-etat-actuel-v1.md` ne bouge plus : il sert de référence pour comparer.
